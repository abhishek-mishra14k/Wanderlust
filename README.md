# 📖 About

**Wanderlust** is a full-stack travel accommodation platform where users can discover destinations, create listings, upload images, write reviews, and securely manage their own properties.

The project follows the MVC architecture and integrates cloud services for image storage and database hosting, providing a production-ready deployment.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/abhishek-mishra14k/Wanderlust.git
```

```bash
cd Wanderlust
```

---

## Install Dependencies

```bash
npm install
```

---

## Create .env File

```env
MONGO_URL=your_mongodb_atlas_url

SECRET=your_secret_key

CLOUD_NAME=your_cloudinary_cloud_name

CLOUD_API_KEY=your_cloudinary_api_key

CLOUD_API_SECRET=your_cloudinary_api_secret

GEOAPIFY_API_KEY=your_geoapify_api_key
```

---

## Run Project

```bash
node app.js
```

or

```bash
nodemon app.js
```

Visit

```
http://localhost:8080
```
